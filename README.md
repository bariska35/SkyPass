# SkyPass
Sky Pass ✈️

Sky Pass, Python ve MySQL kullanılarak geliştirilmiş basit bir havalimanı / uçuş yönetim sistemi projesidir. Kullanıcı giriş işlemleri, uçuş görüntüleme ve veritabanı bağlantıları gibi temel özellikleri içermektedir.

🚀 Proje Özellikleri
Kullanıcı giriş sistemi
Uçuş listeleme ekranı
Kullanıcı bilgilerini görüntüleme
MySQL veritabanı bağlantısı
Basit ve anlaşılır arayüz
Python tabanlı masaüstü uygulaması
🛠️ Kullanılan Teknolojiler
Python
MySQL
SQL
Tkinter (arayüz için)
📂 Proje Dosyaları
index.py → Ana uygulama ekranı
login.py → Giriş sistemi
havalimani_final_hali.sql → Veritabanı dosyası
images/ → Projede kullanılan ekran görüntüleri ve görseller
